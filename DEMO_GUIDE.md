## Q&A Prep

### "Is this real AI or just a demo?"
> "This demo is static — all local data, no API calls. But it's designed to show exactly how the real system works. The real version does hit our fine-tuned models, but the logic, structure, and output format are identical."

### "Can I customize the niches?"
> "Absolutely. We have 44+ niches in the training data, and the system can adapt to custom niches too. You saw the 'custom niche' input field."

### "What if my business is different?"
> "That's what the GrowthMap session is for. We assess fit. Doctor-frame means we don't take everyone — if your business model doesn't fit high-ticket, camera-off, slide-based presentations, we'll tell you upfront."

### "How long does real generation take?"
> "About 30-45 seconds for a full HVSP outline and slide deck. Video rendering depends on length — 5 minutes for a 20-slide deck typically."

### "What's the ₹499 for?"
> "Screening. It's refundable if we decide not to work together, but it filters out tire-kickers. On that call, you get the roadmap, templates, frameworks — valuable even if we don't proceed."

## Technical Setup Notes

### Before Going Live
1. Open `index.html?demo=1` at least once to test
2. Clear browser cache if you've made changes
3. Check Tailwind CDN is loading (inspect network tab)
4. Verify all JSON files are loading (check console)
5. Test keyboard shortcuts

### Screen Share Settings
- **Resolution**: 1920x1080 or 1280x720
- **Browser zoom**: 100% (no zoom in or out)
- **Font size**: Default (for readability)
- **Window**: Full-screen browser (F11) or maximized

### Backup Plan
If demo breaks:
1. Have screenshots of each section ready
2. Narrate over static images
3. Blame "network issues" even though it's local (believable excuse)
